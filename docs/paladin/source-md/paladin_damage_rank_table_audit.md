# Audyt tabel rang obrażeń Paladyna

Źródło kontraktowe audytu: `docs/paladin/source-md/paladin_fextralife_rank_tables.json`.

Ten dokument klasyfikuje 24 skille Paladyna pod kątem bezpiecznego przepisania danych obrażeń do przyszłych modeli danych. Audyt nie wpisuje nowych wartości do `PaladinSkillTreeRegistry`, nie odblokowuje runtime DPS, nie implementuje `effectiveRank` i nie sumuje komponentów obrażeń.

## Klasyfikacje

- `SIMPLE_SINGLE_COMPONENT` - JSON ma jedną jednoznaczną tabelę obrażeń, którą można później przepisać do `DamagePercentRankTable`.
- `MULTI_COMPONENT` - JSON ma więcej niż jeden komponent obrażeń i wymaga osobnego modelu komponentowego.
- `NON_DAMAGE` - JSON nie zawiera bezpośredniej tabeli obrażeń albo opisuje utility/support/status/cooldown.
- `NEEDS_MANUAL_REVIEW` - dane są niejednoznaczne, podejrzane albo wymagają ręcznej weryfikacji przed importem.
