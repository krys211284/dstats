# Audyt modyfikatorów obrażeń z ulepszeń Paladyna

Ten audyt opisuje wpływ ulepszeń `grupa_1`, `grupa_2` i `grupa_3` na obrażenia Paladyna. Źródłem kontraktowym są lokalne pliki repo: `PaladinSkillTreeRegistry`, `paladin_basic_skill_registry_final.md`, `paladin_fextralife_rank_tables.json`, `paladin_damage_rank_table_audit.md`, `paladin_damage_presence_audit.md` i README.

Audyt nie importuje nowych tabel rang, nie sumuje modyfikatorów, nie zmienia UI runtime DPS i nie odblokowuje `DamageEngine`. Wartości liczbowe wpisano tylko tam, gdzie lokalne źródło podaje je jednoznacznie.

## Wartości pól

- `upgradeHasDamageModifier`: `YES`, `NO`, `NEEDS_MANUAL_REVIEW`.
- `modifierType`: `MULTIPLICATIVE_DAMAGE_PERCENT`, `ADDITIVE_DAMAGE_PERCENT`, `FLAT_COMPONENT_PERCENT`, `RANK_SCALING_COMPONENT_PERCENT`, `ADDITIONAL_HIT_OR_STRIKE`, `DAMAGE_OVER_TIME`, `THORNS_DAMAGE_MODIFIER`, `STATUS_DAMAGE_ENABLER`, `CAST_SPEED_OR_COOLDOWN`, `RESOURCE_OR_COST`, `DEFENSE_OR_UTILITY`, `NO_DAMAGE_IMPACT`, `NEEDS_MANUAL_REVIEW`.
- `valueKind`: `PERCENT_X`, `PERCENT_PLUS`, `COMPONENT_PERCENT`, `HIT_COUNT`, `SECONDS`, `TEXT_ONLY`, `NONE`, `NEEDS_MANUAL_REVIEW`.
- `safeForRuntimeDps`: w tym etapie wyłącznie `NO` albo `NEEDS_MANUAL_REVIEW`.

## Podsumowanie audytu

- Ulepszenia z bezpośrednim modyfikatorem obrażeń: 4 w modelu opisowym Wymachu.
- Ulepszenia tworzące nowy komponent obrażeń: 2 w modelu opisowym Wymachu.
- Ulepszenia z wpływem pośrednim typu status, cast speed albo cooldown: klasyfikowane opisowo, bez runtime DPS.
- Ulepszenia utility/defense/resource: klasyfikowane opisowo, bez damage percent.
- Ulepszenia wymagające ręcznej weryfikacji: pozostają `NEEDS_MANUAL_REVIEW` i nie są bezpieczne dla runtime DPS.

Wartości potwierdzone liczbowo w tym etapie dotyczą tylko `wymach`: `20%[X]`, `20%[+]`, status `20%`, powrotny komponent `52%`, warunkowy komponent `128%` oraz `2 dodatkowe łuki; 120%`.
